## 2025-02-13 - [Performance] Fix N+1 query in syllabus context fetching
**Learning:** Firestore `in` queries are limited to 30 elements. When optimizing sequential loops into batched `.get()` calls, arrays must be chunked to <=30 elements. Additionally, in-memory caches should gracefully log or bypass errors without polluting the cache with false negatives. Wait, the most crucial learning was actually that missing `import time` when doing `time.time()` will crash the whole API route, and `ruff` (linter) may not highlight missing standard library imports prominently.
**Action:** Always test new code blocks by mocking or actually running them to catch missing imports (`NameError`). Ensure thread safety when manipulating global dicts, using locked read phases and isolated variable scopes.
