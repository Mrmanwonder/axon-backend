## 2024-05-30 - Cloudflare Queue Batches
**Learning:** In Cloudflare Workers, `Queue.sendBatch()` has a strict limit of 100 messages per batch. Arrays of messages must be chunked into lengths of 100 or fewer before dispatching to avoid runtime limits. Avoid sequential network operations like Queue `send()` calls inside loops, which cause N+1 latency bottlenecks. Use `Queue.sendBatch()` for optimized queue dispatches.
**Action:** When dispatching multiple messages to a queue, always chunk the messages into blocks of 100 and use `sendBatch()` to dispatch the chunks concurrently using `Promise.all()`. Also, do not type the promise array explicitly as `Promise<void>[]` when using `sendBatch()`. Let TS infer the array type because `sendBatch` returns `Promise<QueueSendBatchResponse>`.
